# Sprint plan — 2026-06-24

Organizes the deferred findings (N-backlog `BUG_BACKLOG_2026-06-24.md`, deep-audit
`BUG_BACKLOG_2026-06-24_deep.md`) and the ROADMAP refactor/native work into
sequenced sprints. Ordered by **risk to users first, then leverage**. Each sprint
is a focused unit; items inside are roughly priority-ordered. `[chip]` = a spawned
background task already exists with a detailed prompt.

Gate every commit: typecheck + lint + vitest (touched workspace) → push main →
deploy → verify. After any **wire/protocol or bundled-client change, rebuild the
native apps** (`npm run android:build:debug`; `cd desktop/tauri && npm run build`).

## Sprint 1 — E2EE concept security (CRITICAL/HIGH, crypto) `[chip: D2/D3/D4]`
The deepest weaknesses vs the untrusted-server threat model. Crypto care + round-trip
tests + native rebuild. Highest priority.
- **D2** SECTOR group-key wrap is unauthenticated → full group MITM (admin/server can substitute the wrap key). Bind the wrap to the owner's pinned identity; owner-only PUT; key-change UI warning.
- **D3** Trust-pin/safety-number certifies the legacy static ECDH key, which the DR-v2 DIRECT path never uses → verifying a peer gives no protection. Gate DR send/receive on a verified DR identity; unify the two TOFU stores.
- **D4** X3DH `exchange_public_key` is never signed by the Ed25519 identity key → signing key anchors nothing. Sign + verify the exchange key.
- **N11** LiveKit group-call E2EE key derived from the server-held `LIVEKIT_API_SECRET` (server can decrypt). Move to participant-ECDH-derived keys, or document the trust boundary (comments already corrected).

## Sprint 2 — Privacy & user-facing correctness (HIGH) `[chip: D6/D7]`
"Buttons that lie" + data-loss UX.
- **D6** Armed burn timer silently ignored for ALL media (photos/voice/album/GIF/sticker) → thread `burn_duration_secs` through the media send paths, or disable burn for media + relabel.
- **D7** "Delete account" only wipes the local device; the server account survives → wire `DELETE /me/account` (handle TOTP step-up) or relabel honestly.
- **D18** Switching UI language discards unsaved profile edits (drop `t` from the load effect deps).
- **D30** Display name can't be cleared to empty (`|| undefined` collapses set-empty into omit).
- **D17** Pin-message action has no visible surface → render a pinned bar or remove the menu item + add a toast.

## Sprint 3 — Performance `[chip: D5/D8 + perf cluster]`
- **D5** (HIGH) Read receipts re-sort the whole list + defeat MessageRow memo on every scrolled message → narrow per-row `readAtOverride` prop + batch the writes.
- **D8** Group-chat sender lookup refetches on every read receipt → stable-key memo + merge (not reset) senderMeta.
- **D9** `livekit-client` statically in the main chat bundle → dynamic-import inside the gated join path.
- **D12** `verifySessionJwt` runs 2-3× per request (extra Redis denylist round-trips) → verify once per request, attach to req.
- **D10** Media bubbles presign on every cache HIT → defer/coalesce the eviction probe.
- **D13** `GET /chats` runs 4 sequential queries → `Promise.all` the independent 3.
- **D21** WS audio-relay uses deprecated `ScriptProcessorNode` (main-thread PCM) → AudioWorklet.
- **D22** Per-second burn-tick interval recreated on every store update.
